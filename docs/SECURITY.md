# 安全

一台 NVR 存的是你家 24 小时的画面。这个文件说清楚**哪些地方会咬人**，
以及本项目已经替你堵了哪些、哪些必须你自己做。

## 必做三件事

1. **设登录密码**（装完第一件事，页面会引导你）。
2. **别把 8088 直接透到公网。** 8088 是明文 HTTP，口令穿过局域网时是明文。
   要外部访问：前面放带真证书的反向代理（[DEPLOY.md 第四节](DEPLOY.md)），
   或者用你自己的 VPN（WireGuard / Tailscale 等）。
3. **给 go2rtc 开 BasicAuth**，即使它只绑回环。理由见下。

## 已实现的防护

| 面 | 做法 |
|---|---|
| 口令存储 | PBKDF2-HMAC-SHA256，12 万轮 + 16 字节随机盐；**明文不落盘**，备份配置拿不到口令 |
| 会话 | `secrets.token_urlsafe(32)`，只在内存；Cookie `HttpOnly + SameSite=Strict` |
| CSRF | 靠 `SameSite=Strict` 挡掉：跨站请求不带这个 Cookie |
| 暴力破解 | 按 `IP+用户名` 限流：15 分钟 8 次失败 → 冷却 30 秒 |
| 会话生命周期 | 滑动续命，上限可配（默认 24 小时，最短 5 分钟）；改密码即刻作废所有旧会话 |
| 认领窗口 | 未设密码时**只放行"设密码"这一个接口**，录像/配置/直播流全部要登录态 |
| 会话表 | 最多 200 条，超出按插入序淘汰（防内存涨） |
| 静态资源 | 非 `/api` `/live` `/rec` 前缀放行 —— 页面本身要能告诉访客"你还没登录" |
| 健康检查 | `/api/health` 免登录，但只回**收敛结论**；存储占用、看门狗心跳、每路明细只在登录态下发 |
| 录像下载 | `/rec/**` 要登录态；路径经 `normpath` + `realpath` 双重归一后强制落在录像根内（`..` 穿不出去），且只允许命中文件 —— 不做目录列表 |
| 地址脱敏 | 对外回显的 RTSP/流地址里的口令会被替换成 `user:***@`（`_mask_url`） |
| 网关 socket | 飞牛统一网关模式下按 `umask 007` 创建（0770），与飞牛应用惯例一致 |
| TLS | 内置自签 8443（对讲的硬性要求，见 README）；对外请换真证书 |

## go2rtc 这一层为什么最容易漏

go2rtc 的 API 会把它自己的完整配置回给任何能连上它的客户端 —— 里面就有
**米家 `passToken`**，拿到它等于拿到你米家账号的设备控制凭据。

两个反直觉的点：

- `api.listen: "127.0.0.1:1984"` **不等于安全**。go2rtc 源码
  `internal/api/api.go` 判的是 `if localAuth || !isLoopback(...)`：
  `local_auth` 默认 `false` 时，"只绑回环"等于**没鉴权** ——
  同一台机器上的任何进程（包括别的容器、别的用户）都能调你的云台、读那份配置。
- 所以 `docker/go2rtc.yaml.example` 里 `username`/`password` 留空是**故意让你填**，
  并且 `local_auth: true` 已经写死在模板里。填完这一项再联网。

HomeEye 侧对应 `ptz.g2r_user` / `ptz.g2r_pass` 两个设置项，填成一样的即可。

## 摄像头自身的账号

- RTSP 摄像头的用户名/口令存在 `data/config.json` 里（明文，因为要拼进
  `rtsp://user:pass@host/...` 交给 ffmpeg）。所以 **`data/` 目录权限就是这些凭据的
  权限边界**：不要把它挂给别的容器、不要放进任何同步盘、不要提交到 git。
- 米家授权缓存存在 `data/xiaomi_auth/`。
- Docker 版容器内进程是 root（`HE_DATA_DIR=/data`）；飞牛 fpk 版是 `homeeye`
  应用账号，目录权限由系统管。两种都别把 `data/` 设成 777。

## 对讲

上行是浏览器采到的 PCM 分块 POST 给 HomeEye，再转 G.711 推给 go2rtc。
这条链路上的敏感点是：**它能让你家的摄像头喇叭出声**。所以它和其它写操作一样
在登录闸门后面，且必须走 HTTPS（浏览器规矩，不是本项目的偏好）。

## 日志

`info.log` 与容器日志里会出现摄像头地址（含 `user:pass@` 形式的 RTSP URL 片段）。
本项目在 `/api/state` 与健康检查里对 token 类字段做了截断，但**日志文件本身不是
脱敏存储**：不要把 `data/` 或容器日志上传到任何公开地方、不要把日志卷挂给别的服务。
