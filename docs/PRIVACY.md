# 隐私与数据

## 数据存在哪、会不会出网

| 数据 | 位置 | 出网？ |
|---|---|---|
| 实时画面 | 只在内存里过一遍（环形缓冲，最近约 32KB 批次） | 否 |
| 录像 | `data/recordings/<摄像头ID>/*.mp4`（fpk 版在 `@appdata/homeeye`） | 否 |
| 配置（含摄像头口令、米家凭据引用） | `data/config.json` | 否 |
| 米家授权 token | `data/xiaomi_auth/` | 建立会话时用，画面本身不走服务器 |
| 登录口令 | `config.json` 里的 PBKDF2 派生值 + 盐 | 否 |
| 多用户账号 | `config.json` 的 `users` 段（同样只存派生值 + 盐） | 否 |
| 会话 token | 进程内存，重启即失效 | 否 |
| 访问审计 | `data/audit/YYYYMMDD.jsonl`，本地保留 90 天 | 否 |
| 遮蔽区域 | 跟着摄像头写在 `config.json` 里（只有归一化坐标） | 否 |
| 导出的片段 | `data/exports/<任务号>.mp4`，7 天后自动清理 | 否（除非你自己发出去） |
| 分享链接 | `data/shares.json`（token + 到几点 + 被访问次数） | 否 |
| AI 事件与描述 | `data/events/<日期>.jsonl`（类别标签 / VLM 一句话描述） | 见下节 |
| 日志 | `info.log` / 容器日志 | 否 |
| 遥测、崩溃上报、"检查更新" | —— | **本项目一行都没有** |

HomeEye 不内置任何统计、广告、许可证校验或云端账号。它主动发起的对外请求只有：

1. 你配置的摄像头地址（RTSP/ONVIF，局域网内）；
2. 小米云：扫码授权、设备列表、`did`/本地地址查询、P2P 会话协商 ——
   **走的是米家自己的协议，用的是你自己的米家账号**；画面是与设备 P2P 直连，
   不经过小米的内容服务器，也不经过本项目的任何服务器（本项目没有服务器）；
3. go2rtc（如果你部署了它）：本机回环；
4. SMTP（如果你配了邮件告警）：你填的那台邮件服务器；
5. **VLM 图文描述**（`ai.vlm_enabled`，**默认关**）：你填的那 OpenAI 兼容地址。
   开的时候会把**一帧 640 宽的 JPEG**（base64）POST 出去换一句话描述 ——
   这是本项目唯一会把画面内容发给外部服务的开关，关着就一个包都不发；
6. **rclone 冷层归档**（`archive.enabled`，**默认关**）：你自己在 rclone 里配的那台远端。

关掉小米那一路的方法：不加小米摄像头，或不装 SDK（本仓库默认不含）。

## 保留与删除

- **保留天数**（`storage.retention_days`）与**容量上限**（`storage.budget_gb`）
  两个都填时同时生效，任一命中就开始删最旧的分段。
- 删除是真删除：文件从磁盘移除，不做软删。
- 卸载应用**不删录像**（刻意的：把几百 GB 画面在一次卸载里抹掉是不可逆事故）。
  要彻底清除：
  ```sh
  rm -rf data/            # Docker 版：仓库根下的 data/
  # fpk 版：@appdata/homeeye 与共享目录 homeeye/data
  ```
- 摄像头侧的 SD 卡录像归摄像头自己管，不在本项目的清理范围内 ——
  如果你开了 SD 卡回补，画面在卡上也有一份。

## 谁能看、看了什么、给出去什么（1.3.0）

这一段是"隐私与合规"在代码里的实际落点。**做了什么、没做什么**都写明白，
不拿方向当承诺。

### 遮蔽区域：烧进像素，不是盖在屏幕上

- 每路最多 8 块矩形，坐标是画面归一化的 0~1（换分辨率不用重画），
  在设置页里直接圈在这路画面上。
- 落到 ffmpeg 是 `drawbox=x=iw*…:y=ih*…:w=iw*…:h=ih*…:color=black@1:t=fill`，
  **在编码环节就涂黑**：实时流、录像、导出、小米那一路共用同一条链路，
  抽帧比对拿到的是同一片黑。实测（320×240 全屏遮蔽）：遮蔽导出 YAVG=16.0，
  同一段不遮蔽 YAVG=210.0。
- 代价是**这一路必须重编码**：源已经是 H.264 也不能再 `-c:v copy`。
  摄像头卡片与设置页都写着"这一路会重编码"，CPU 的账不藏。

### 访问审计：本地 JSONL，90 天

- 落 `data/audit/YYYYMMDD.jsonl`，一天一个文件，写入时顺带清掉 90 天前的；
  内存里另留最近 400 条给页面查。没有数据库，`tail`/`grep` 就能看。
- 记的动作（页面筛选用的 `GET /api/audit/kinds` 就是这一份）：
  `login` / `login_fail` / `login_locked` / `logout` / `password_change` /
  `user_create` / `user_update` / `user_delete` / `cam_create` / `cam_delete` /
  `cam_denied` / `cam_secret_reveal` / `privacy_update` / `settings_change` /
  `live_view` / `rec_view` / `export_create` / `export` / `export_download` /
  `share_create` / `share_hit` / `share_revoke` / `integrity_scan` /
  `archive` / `archive_run` / `archive_cancel`。
- 设置变更只记**改了哪些键名**，不记键值；字段名里带 `pass`/`token`/`secret`/
  `hash`/`salt` 的值一律先变成 `***` 再落盘。
- **没做**：审计自身的防篡改（它就是个文件，拿到 root 的人能改能删）、
  外发（不转 syslog —— 少一条出网的路）。

### 谁能看哪几路

- 角色两档：`admin` / `read`；`read` 带**按摄像头授权**的白名单（`cams`）。
- 权限判在**数据出口**而不是把按钮藏起来：直播流、录像文件、回放分段、
  H.264 回放、录像清单、播放列表、事件、缩略图、快照、导出、分享、用户、
  审计、归档、设置、流地址 reveal —— 越权一律不给内容。
- 未授权的摄像头回 **404 而不是 403**，并且在 `/api/state` 的列表里根本不出现：
  403 等于告诉家里其他人"这路存在、装在哪儿"。

### 给出去的东西

- **导出**：默认套用这一路的遮蔽（页面勾选框默认开着，接口默认 `mask=true`）；
  下载文件名是 `homeeye-<任务号>.mp4`，**不带摄像头真名**；
  单次最多 6 小时，产物 7 天后自动清理。
- **分享链接** `/share/<token>`：免登录、拿到链接的人都能看，最长 30 天、
  可随时撤销；页面只放这一段视频，没有应用外壳，也点不到其它摄像头。
  过期 / 被撤销 / 文件已清理 三种情况各自给一句人话（都是 404，不装死）。
  **注意**：分享页顶部会显示这一路的**名字** —— 所以"给摄像头起什么名"
  在你准备发链接之前就已经是隐私问题（"主卧"这种词别写）。
- **流地址口令**：接口与日志都不回传明文。列表只给掩码形态
  （`rtsp://admin:***@host/…`），连 ffmpeg/ffprobe 报错原话里的口令也一起抹掉；
  带口令的那路会标 `url_secret`，页面据此决定要不要放"显示完整地址"按钮。
  那个按钮是**独立接口**、只放行管理员，每点一次在审计里落一条 `cam_secret_reveal`。
  只改名字/备注不会把口令写坏：保存掩码地址时会自动把原口令贴回去。

### 保留期与冷层

- 录像保留天数在**落盘前**钳到 0~365 天（0 = 不自动删，那是明确的运维选择，
  配合容量上限用）；填 3650 会被钳成 365，并且页面上会说明钳过。
- 导出产物 7 天、分享链接最长 30 天、事件明细默认 30 天（`keep_events_days`）、
  审计 90 天 —— 这四个是代码里的上限，页面上调不出更久的数。
- 可选的 rclone 冷层归档：搬走比 `older_days` 更老的分段，
  `rclone lsjson --stat` 核对远端字节数与本地一致以后**才**允许删本地
  （`delete_local` 默认关）。这台机器没有 rclone 或没配 remote 时不装忙，
  状态接口把原因直说出来。

### 明确没做

- 录像加密存储（密钥管理成本比这一版功能高，先看上面的遮蔽 + 审计够不够）。
- 人脸识别、车牌识别、自动给陌生人打码（误判代价太高，需要更强的模型）。
- 软删除 / 回收站（清理就是真删除，见上一节）。
- Web Push（要 VAPID/ES256 签名，后端只用标准库、不引第三方加密包；
  页面里用的是本地通知 + 点击深链）。

## 你的法律义务（这部分不是可选的）

软件不上传画面，**不等于你的使用是合法的**。拍摄行为本身受法律约束：

- **中华人民共和国**：自然人图像属于《个人信息保护法》下的敏感个人信息，处理需
  单独同意并有明确合理目的；公共场所图像采集另有严格限制（不少地方性法规要求
  备案与显著标识）。楼道、门口、院外这类**越过自家边界**的取景，通常需要向被拍摄人
  作显著告知；拍到邻居、快递员、访客同理。
- **欧盟/EEA**：适用 GDPR。"家用例外"只在画面完全不出自家边界时成立；
  镜头扫到街道、楼道、他人住宅即不适用，你会成为数据控制者。
- **家庭内部**（保姆、租客、同住人、未成年子女）：需要知情与同意渠道，
  且不得用于隐蔽监控。
- 录像用于纠纷举证时，取证方式的合法性会影响它能否被采信。

本项目的保留天数/容量上限功能是为了让"只留必要时长"这件事**可执行**，
不构成法律意见。拿不准就问律师，或者把镜头往里挪。
